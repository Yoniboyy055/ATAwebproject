# Recommendation for Claude's Next Work Package — WP-03 v0.1

## Primary recommendation — WP-04: Launch-Critical Clarification Pack for ATA

**Why now.** Three work packages have produced a complete, evidence-graded map of what is unknown. WP-01 catalogued the conflicts, WP-02 built the content model around them, WP-03 removed every gap that external research could remove. What remains is almost entirely **ATA-held facts and decisions** — and that set is now precise enough to ask about in one focused pass rather than another broad questionnaire.

This was WP-04 in the original work brief, and nothing since has displaced it. It is also the last thing standing between the project and a page that can actually render honest content.

**Scope:**
1. A single prioritised clarification document for ATA, each item citing its source record ID (V-xxx, T-xx, A-xx) so ATA can see why it is being asked.
2. Ordered by launch-blocking impact, not by topic — flagship identity, pricing model, itinerary confirmation, booking/payment reality, identity set, media, then the rest.
3. **Three newly urgent items WP-03 surfaced** that were not in the original WP-04 outline:
   - **V-019 travel permits** — potentially affects the feasibility of the flagship's core segment.
   - **V-014 seasonal decision** — now decidable, because the climate facts exist.
   - **A-02 Massawa condition** — needed to unlock the package's strongest trust content.
4. For each item: what ATA must supply, why it is blocking, what happens if it is deferred, and — where useful — a safe interim posture so launch is not held hostage to any single answer.
5. Explicit separation of *facts ATA must supply* from *decisions ATA must make* — these need different kinds of thinking and often different people.

**Deliverable:** `12 Client Approvals/ATA_LAUNCH_CRITICAL_CLARIFICATIONS_DRAFT_v0.1.md`, per the original work brief.

**Why not more research:** the remaining unknowns are not researchable. Prices, dates, capacity, suppliers, access, safety posture, policies and promises cannot be verified from outside ATA. Further research would produce volume without reducing risk.

## Secondary — small and worth doing alongside

**A. Publishable-content shortlist (half a day).** Four rows in the dashboard matrix (D-02, D-04, D-05, D-08) are fully eligible now. A short note telling Codex and ATA exactly which values can be entered and released immediately would let a real page show honest, verified content before the clarification cycle completes. Momentum matters, and it demonstrates the pipeline working end to end.

**B. UNESCO verbatim upgrade (minutes).** If anyone opens `whc.unesco.org/en/list/1550/` and supplies the page text, every UNESCO claim moves from "corroborated extract" to primary-source verified, and D-01/D-03 unblock. Cheapest risk reduction available in the whole project.

## Explicitly not recommended next

- **More destination research.** The five WP-03 topics are done. Additional destinations (Dahlak, Keren, Nakfa, Qohaito, Filfil) are deferred until ATA activates packages beyond the flagship — researching them now would be speculative work against an unconfirmed catalogue.
- **Any UI or copy implementation by Claude.** Implementation is Codex's; WP-02 already handed over the content model and CTA rules.
- **Drafting policies, cancellation terms, or safety guidance.** Professional review items, not writing tasks.
- **Revisiting the WP-02 copy contract.** It is current with the 15-state lifecycle and needs no change until Codex's transition-pair detail becomes available.
