# ATA WP-03D Placeholder Behavior Specification v0.1

Store null plus explicit status, never fake data.

| Missing value | Controlled wording |
|---|---|
| Price | “Request current pricing” |
| Dates | “Dates to be confirmed” |
| Availability | “Contact ATA for availability” |
| Final details | “Final details confirmed directly by ATA” |

Production hides unverifiable sections unless controlled wording is approved. Placeholders never imply a secured seat, reservation, payment, itinerary, price, or booking.
