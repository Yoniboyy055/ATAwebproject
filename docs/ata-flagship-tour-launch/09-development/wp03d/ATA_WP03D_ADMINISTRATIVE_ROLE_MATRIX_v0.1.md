# ATA WP-03D Administrative Role Matrix v0.1

| Role | Allowed | Prohibited |
|---|---|---|
| ATA Owner | membership, approval, release, manual confirmation | bypass controls |
| ATA Administrator | delegated administration/operations | ownership transfer |
| ATA Content Manager | draft/submit/evidence | approval/release/confirmation |
| ATA Operations Manager | request management; delegated confirmation | content/access ownership |
| YK Technical Administrator | approved technical maintenance | ATA fact approval/confirmation |
| Read-only Auditor | controlled reads/audit | mutation |

Assignments are invitation-only, environment-scoped, revocable, and audited. Client parameters never determine roles.
