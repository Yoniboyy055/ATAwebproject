# ATA WP-03D Audit-Event Specification v0.1

Record immutable event ID, actor subject, resolved role, action, entity type/ID, previous/new values, timestamp, environment, request/tour/evidence/approval/release references, and correlation metadata.

Audit membership, edits, verification, approval, release, suspension, transitions, assignment, manual confirmation, export, and failed authorization. Events are append-only/server-written. Redact sensitive values. Retention/access require owner and legal approval.
