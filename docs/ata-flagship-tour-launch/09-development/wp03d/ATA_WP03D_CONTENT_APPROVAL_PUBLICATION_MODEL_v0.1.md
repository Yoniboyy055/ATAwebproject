# ATA WP-03D Content Approval and Publication Model v0.1

Lifecycle: `DRAFT` → `SUBMITTED` → `UNDER_REVIEW` → `VERIFIED` → `APPROVED` → `RELEASED`, plus `SUSPENDED` and terminal `ARCHIVED`.

Public rendering requires a non-null value, public intent, required current evidence, verification, ATA-authorized approval, separate release, active validity window, and no suspension/supersession.

YK Systems technical authority does not confer ATA business approval. Post-release changes create a new version.
